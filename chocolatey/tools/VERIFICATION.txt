VERIFICATION INFORMATION

How to verify the binaries:
1. The binaries are downloaded directly from the official GitHub Release page:
   https://github.com/MoriokaReimen/Task-Fighter/releases

2. You can verify the SHA256 checksums manually by checking the official release assets or by downloading the file and running:
   Get-FileHash -Path "path\to\downloaded.zip" -Algorithm SHA256
